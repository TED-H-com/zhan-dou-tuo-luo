## 一句話總結

Beyblade X 不是單純比誰轉最久。自旋勝利通常只拿 1 分，撞出場 / 爆裂可以拿 2 分，Xtreme Finish 可以拿 3 分，而一場先到 4 分就結束。所以高手不是只買一顆神物，而是用 3v3 牌組把攻擊、穩守、收尾和反制配置好。

## 新手購買順序

1. 先買 Takara Tomy / 日版系統，認真打比賽時重量、零件可調性和主流環境比較接近。
2. 第一顆主力選穩定型，例如 Wizard Rod 系列，用來練中心控盤、角度、穩定發射。
3. 第二顆補攻擊型，例如 Phoenix Wing、Aero Pegasus、Dran Buster 這類能搶 2 到 3 分的角色。
4. 第三顆補反制或收尾，例如 Cobalt Dragoon、Silver Wolf 或當地 meta 常見的防守 / 持久配置。
5. 不要一次把錢花在「網路說最強」的一顆上。先看你打的是 1v1、3v3、店家賽還是官方賽，禁用表與勝利條件可能不同。

## 3v3 牌組思路

- 搶分手：負責 Over Finish、Burst Finish、Xtreme Finish，一次把分差拉開。
- 穩守手：負責減少自爆、守中心、逼對手攻擊失誤。
- 反制手：針對當地常見牌組，例如專打右迴持久、抗攻擊、或處理 Wizard Rod 類型。

## AI Agent 可以怎麼幫你變強

- 幫你把賽制轉成「分數模型」，不要只憑感覺選陀螺。
- 幫你整理當地 meta：誰常用 Wizard Rod、誰愛攻擊型、哪種場地最常出現。
- 幫你做牌組假設：這三顆能不能互補，零件有沒有重複，遇到攻擊 / 持久 / 防守時怎麼排。
- 幫你寫訓練菜單：每天練 20 次平射、20 次斜射、10 次弱射控盤，記錄成功率。
- 幫你做賽後復盤：輸是因為發射角度、場地、對位、還是牌組本身不合理。

## 注意

Beyblade X 的環境會變。新零件、官方禁用表、店家規則、地區賽制都會影響「最強」答案。這份筆記適合當作戰術框架，不是永久排行榜。
